Local kernel · offline by default

Index the work. Route the cheapest capable path. Keep the receipt.

GrokGeneral is the local control plane for the GrokBot ecosystem. It indexes projects and resources, packages narrow context, records decisions, and surfaces temporary capacity. It is not a general-purpose autonomous agent and does not call a paid model on the default path.

Install and run See the model

What it owns

Projects, resources, tasks, policies, usage, events, and cache metadata in a local SQLite state directory.

How it decides

Routing is deterministic and cost-aware. Premium or GrokBot capacity is used only when policy says it is justified.

What it refuses

Network, spend, push, posting, and destructive actions require explicit approval. No credentials are stored for providers.

Run it locally

Python 3.11 or newer. No third-party runtime dependencies.

./gg --help
./gg init --scan
./gg status --json
./gg opportunities --json

Default state lives in ~/.grokgeneral/. The offline test suite does not require a network or an API key.

GrokGeneral is a local kernel, not a hosted agent. Source stays on your machine.
