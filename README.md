# GrokGeneral

GrokGeneral is a local-first Python kernel and control plane for the GrokBot ecosystem. Its package metadata defines the `gg` command. This repository is not yet marked as a release; package publication is pending license, source, and CI review.

- **Version in repository:** `0.1.0`
- **License:** License status must be resolved before distribution
- **Source:** [GitHub](https://github.com/M4G3LL4N0/grokgeneral)
- **Project site:** [https://grokgeneral.vercel.app](https://grokgeneral.vercel.app)

## Installation

The command below is the intended PyPI installation form; it is not evidence that this distribution has been published yet.

```sh
pipx install grokgeneral
```
